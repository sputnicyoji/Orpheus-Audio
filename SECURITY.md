# Security Policy

## Supported versions

Security fixes target the current `0.2.x` compatibility line.

| Version | Supported |
| --- | --- |
| `0.2.x` | Yes |
| `< 0.2` | No |

## Report a vulnerability

Do not open a public issue for vulnerabilities, credentials, signing material,
or device identifiers.

Use
[GitHub private vulnerability reporting](https://github.com/sputnicyoji/Orpheus-Audio/security/advisories/new)
and include:

- affected package version or commit;
- Unity version and target platform;
- minimal reproduction steps;
- impact and reachable attack surface;
- logs with credentials, local paths, and device identifiers removed.

If a credential was committed, revoke or rotate it before reporting. Removing
it from the latest commit does not remove it from Git history or release
assets.
